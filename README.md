## Cómo abordo un proyecto

1. **Comprender el problema:** objetivos, usuarios, proceso actual y restricciones.
2. **Delimitar la solución:** alcance, datos, interfaces y criterios de aceptación.
3. **Construir y verificar:** implementar incrementos pequeños con pruebas reproducibles.
4. **Documentar y entregar:** explicar el uso, las limitaciones y las opciones de mantenimiento.
